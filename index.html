Featured Academic Innovation · Full project

Autonomous IoT Robot for Real-Time Multi-Gas Environmental Monitoring

Embedded Systems · IoT · Environmental Monitoring

ESP32Gas SensingBlynk IoTTemperature & Humidity

The problem

Fixed environmental monitoring devices may miss variations in gas concentrations across different parts of an industrial or enclosed space.

The solution

An autonomous mobile robot built around an ESP32 microcontroller that moves through an area, collects environmental sensor readings, and sends data to the Blynk IoT platform for remote visualization.

My contribution

Personally handled the project from scratch, including hardware assembly, circuit connections, microcontroller setup, sensor integration, programming, and Blynk IoT configuration.

What it does

  • Mobile environmental monitoring
  • Monitors multiple gases, temperature, and humidity using its integrated sensors
  • Temperature and humidity monitoring
  • Sends sensor readings to Blynk IoT for remote visualization
  • Uses an LED to signal successful data transmission
